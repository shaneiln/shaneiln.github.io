Add the names font to this folder:
  ADayWithoutSun.ttf   (or ADayWithoutSun.woff2)
Download "A Day Without Sun" from a font site such as 1001fonts.com or fontspace.com
(Canva doesn't let you export its fonts). It is listed as free for personal, non-commercial use (CC BY-NC) -
check the licence in the download. Until the file is added the names show in Antonio, a similar thin condensed font.
All other text uses Cormorant Garamond, which loads automatically from Google Fonts.
