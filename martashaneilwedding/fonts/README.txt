Add these font files to this folder:

1. wasted-vindey.regular.ttf   - "Wasted Vindey Regular" (all text on the site).
   Free for personal use on several font sites (e.g. cufonfonts.com, font.download); commercial use needs a licence.
   Keep the file name exactly as above (the site also accepts .otf, or WastedVindey.ttf / WastedVindey.otf).
2. ADayWithoutSun.ttf (or .woff2) - "A Day Without Sun" (names on the splash page).
   Listed as free for personal, non-commercial use (CC BY-NC) - check the licence in the download.

Until a file is added the page falls back to Georgia (text) or Antonio (names).
